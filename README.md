# Darkn3rd Tools

## How do I install these formulae?

`brew install darkn3rd/tools/<formula>`

Or `brew tap darkn3rd/tools` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "darkn3rd/tools"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
